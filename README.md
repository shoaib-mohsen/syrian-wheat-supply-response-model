Work has moved to a new project covering both wheat and barley supply response models:

👉 **[Wheat & Barley Supply Response Models in Syria](https://github.com/shoaib-mohsen/syria-cereal-supply-response)**

## What this repository contains

- **Title:** Empirical Research of wheat farmers' responsiveness to government price policies in Syria (2002–2023)
- **Scope:** Wheat only, annual data, 2002–2023 (22 observations)
- **Core identity:** Q = A × Y (production decomposed into area and yield)
- **Tools:** R 4.5.0

## How to treat the results here

- Do not use the code in this repository. Some bugs and issues may not have been fixed, so the scripts may produce incomplete or incorrect results.
- The estimates in this repository come from an earlier data construction and specification, and are **not** the final results of the research project.
- Please do not cite figures from this repository as final. Cite the successor project instead.
- The sample is small, and the data sources differ from those in the successor project.
